## Description
Diago does not currently support sketch rendering or LaTeX labels. The previous embedded Rough.js and MathJax adapters and their `dowdiness/js_engine` dependency were removed because they were unstable across supported targets.

The long-term goal is to re-enable these features only when the MoonBit community provides mature, reusable implementations. Diago should not develop replacement engines from scratch solely to restore them.

## Design
Periodically evaluate community implementations as possible replacements. A replacement must preserve Diago's public rendering behavior, support native, JavaScript, and WebAssembly targets, and retain normalized SVG parity with D2 for both Dagre and ELK layouts.

Once suitable implementations exist, integrate the two features independently and remove their fixtures from the explicit skip list only after parity and multi-backend validation.

## Acceptance Criteria
- [ ] A community sketch implementation can replace the embedded D2 Rough.js runtime while preserving the normalized D2 sketch SVG corpus on all supported targets.
- [ ] A community LaTeX implementation can replace the embedded MathJax runtime while preserving D2-compatible SVG output and text metrics on all supported targets.
- [ ] Diago's Dagre and ELK example parity tests pass after both replacements.
- [ ] Native, JavaScript, and WebAssembly builds and tests pass with the replacement implementations.
- [ ] The relevant fixtures are removed from `testdata/d2-official/skipped.tsv` and pass compatibility and normalized parity gates.
