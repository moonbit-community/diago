## Question

Which block identity, source span, Wasm error metadata, message, and severity
fields form the shared diagnostic model, and how should each host expose those
diagnostics without discarding successful transformations?

## Close Notes

Use one error diagnostic carrying stable code, Wasm metadata, document/block
identity, message, and whole-fence range. Store it in the host channel before
calling an optional callback; per-fence errors do not throw by default.
