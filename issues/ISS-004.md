## Question

How should each embedded diagram derive a deterministic salt that prevents SVG
ID collisions across repeated diagrams and combined Markdown documents without
making unrelated document edits churn every SVG identifier?

## Close Notes

Hash the logical document ID, diagram-source digest, and same-source occurrence
into a stable block ID, then pass `markdown:<blockId>` through Diago's existing
salt option. Do not post-process SVG text.
