## Question

Given that the existing Wasm transaction has no filesystem resolver and Wasm
ABI changes are out of scope, what explicit behavior should the npm package
provide when a Diago fence contains imports?

## Notes

- 2026-07-20: Wasm corpus probe found 171 source-only successes and 12 import
  failures among the 183 otherwise supported official fixtures.
- 2026-07-20: Final import policy recorded in
  `docs/markdown-package-design.md#imports`.

## Close Notes

Version 1 performs no filesystem or network import resolution. The existing
Wasm `ir` failure becomes `DIAGO_IR`, the original fence remains, and other
fences continue. Future imports require a separately designed in-memory Wasm
protocol.
