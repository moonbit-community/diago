## Close Notes

Use one Node.js 20+ ESM package with explicit root, markdown-it, remark, and
VitePress exports. Keep one version-matched Wasm artifact private, load it
relative to `import.meta.url` with `node:fs/promises`, cache the module and
default-renderer promises, and retain an independent renderer factory. Reuse
the existing ABI and export validation as a release gate.
