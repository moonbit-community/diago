## Question

What trust, sanitization, CSP, link, image, style, and raw-HTML assumptions must
the package state when it embeds Diago SVG directly into Markdown consumed by
markdown-it, remark, and VitePress?

## Close Notes

The first release supports trusted project-authored Markdown only. Generated
inline SVG is active content, and current Diago Markdown labels may inject raw
XHTML with `safe=false`; host Markdown settings are not a sanitizer for that
output. Document CSP, link, image, font, and style consequences, and defer
untrusted input until Diago has an explicit safe-render mode.
